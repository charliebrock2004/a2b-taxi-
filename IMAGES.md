# Photo slots

Save a JPEG with the exact file name below into `public/images/` and redeploy. The site picks it
up automatically, resizes it for each screen and serves AVIF/WebP. A slot with no file shows the
charcoal contour texture (or, for the smaller slots, simply does not appear).

Export at the stated width, quality around 80. Dark, low-saturation images suit the design:
text sits on top of the hero images, so keep the lower-left third of each one uncluttered.

| File | Where it appears | Width | Subject |
| --- | --- | --- | --- |
| `hero.jpg` | Homepage hero | 2400 | Black executive car on a Perthshire road, hills behind |
| `why.jpg` | Homepage, Why choose A2B | 1400 | Vehicle interior or driver detail |
| `local.jpg` | Local private hire | 2000 | Crieff street scene or car in town |
| `airport.jpg` | Airport transfers | 2000 | Airport departures, kerbside |
| `rail.jpg` | Railway station transfers | 2000 | Station platform or forecourt |
| `wedding.jpg` | Wedding transport | 2000 | Wedding venue arrival |
| `hospital.jpg` | Hospital transfers | 2000 | Calm, respectful: car door, passenger helped in |
| `day-trips.jpg` | Day trips and events | 2000 | Distillery, racecourse or Perthshire scenery |
| `golf.jpg` | Golf trips | 2000 | Perthshire golf course |
| `ports.jpg` | Port transfers (homepage list) | 1600 | Ferry port |
| `services.jpg`, `areas.jpg`, `about.jpg`, `contact.jpg` | Page heroes | 2000 | Scenic Strathearn roads |
| `about-detail.jpg` | About page | 1400 | The actual A2B vehicle or driver, if available |

Rules that matter for this client:

- Use A2B's own fleet photographs wherever possible. If you use stock, pick images where the make
  and badge are not identifiable, so the site never implies A2B owns a particular car.
- Only use images you hold a licence for. Keep a note of the source of each one.
- Every service image also appears as a tile in the service lists once its file exists.
